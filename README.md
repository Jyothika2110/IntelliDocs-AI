# 📄 IntelliDocs AI

An AI-powered PDF chatbot that allows users to upload documents and ask questions using Groq LLM.

## 🚀 Features

- 📄 Upload PDF documents
- 🤖 Chat with PDF using AI
- 🔍 Search previous chats
- 📑 PDF Preview
- 🌙 Dark / Light Mode
- 📤 Export Chat as PDF
- 📝 Export Chat as TXT
- 🗑 Delete Individual Chats
- 🧹 Clear Chat History

## 🛠 Tech Stack

### Frontend
- React
- TypeScript
- Vite
- Material UI

### Backend
- Spring Boot
- Java
- Spring Security
- Apache PDFBox

### Database
- MySQL

### AI
- Groq LLM API
